---
title: "Fallback relay"
description: "Planned fallback for restricted networks."
---

An operated default relay is planned for cases where direct peer connectivity fails. Although a relay client component exists, the current transfer workflow does not automatically use it, and no supported relay deployment or configuration procedure is established here.

The intended design forwards end-to-end encrypted data without giving the relay the file contents or invitation secret. The relay can observe network metadata such as IP addresses, timing and traffic volume. Integration, abuse controls, operations, independent security review and real-network verification remain release tasks. Optional self-hosting is a future capability.
