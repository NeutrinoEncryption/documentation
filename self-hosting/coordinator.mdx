---
title: "Rendezvous coordinator"
description: "Planned discovery service."
---

A default, operated discovery service is planned for setup-free internet transfers. The current transfer workflow does not use a public rendezvous coordinator. There is no supported coordinator deployment or configuration procedure to follow here yet.

The design must authenticate candidate exchange without exposing invitation secrets or file contents to the service. Operators can still observe network metadata such as IP addresses, timing and traffic volume. The threat model, retention policy, service operation and security review remain release tasks. Optional self-hosting is a future capability.
