title: "Roadmap"
description: "Released File Transfer and the planned Sync, Git, and Mesh capabilities."
---

File Transfer is the released workflow. Neutrino is closed source by Peretas Technologies; only the relay and documentation are open source. See [Changelog](/changelog) for shipped changes.

| Capability | Availability | Intended direction |
| --- | --- | --- |
| File Transfer | Available | Secure file/folder delivery with direct connections and relay fallback |
| [Sync](/guide/sync) | Not yet available | Multi-host folder synchronization and conflict handling |
| [Git over Neutrino](/guide/git) | Not yet available | Peer-to-peer repository hosting and replication |
| [Mesh networking](/guide/mesh) | Not yet available | Encrypted virtual interfaces between peers |

Internal crates, screens, and parsed commands are implementation work, not availability evidence. No release date is promised here. Releases require integrated tests and real-network evidence at the scope claimed.

<Warning>Neutrino has not been independently security-audited. Do not use it for confidential files.</Warning>
