<Warning>In development / not yet available as a complete end-to-end product.</Warning>

The planned design uses FastCDC chunks, BLAKE3 Merkle-DAG state, and deterministic conflict branching. Core components do not yet provide complete multi-host folder synchronization. Do not rely on this subsystem for backups, repository durability, or protected connectivity.

Use the [quickstart](/quickstart) for released file and folder transfers.
