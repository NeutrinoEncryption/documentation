<Warning>In development / not yet available as a complete end-to-end product.</Warning>

The planned design uses `git-remote-neutrino` and multiplexed packfile streams. The helper and core code do not yet provide complete peer-to-peer Git hosting and replication. Do not rely on this subsystem for backups, repository durability, or protected connectivity.

Use the [quickstart](/quickstart) for released file and folder transfers.
