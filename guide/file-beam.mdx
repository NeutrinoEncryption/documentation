---
title: "Ephemeral file beam"
description: "Try the current direct file transfer beta."
---

The current transfer sends over QUIC to the address in the sender's invitation. It works only when that address is reachable, such as loopback or an appropriate LAN. Automatic internet discovery, NAT traversal and relay fallback are planned and are not integrated.

```bash
neutrino send /path/to/file
neutrino receive <SESSION_CODE> /path/to/destination
```

Share the actual `neu1_` code privately: it contains an authentication secret. The receiver stages data and checks file integrity before finalizing it. Real interruption and reconnection with resumption remains a release verification task; do not assume it is reliable yet. See the quickstart and product roadmap for status.
