## Global Options

The `neutrino` CLI accepts several global flags applicable to all subcommands:

```bash
neutrino [OPTIONS] <COMMAND>
```

| Flag | Argument | Description |
| :--- | :--- | :--- |
| `--data-dir` | `<DIR>` | Override the default data directory (default: `~/.neutrino`). |
| `--daemon-bin` | `<BIN>` | Path to explicit `neutrinod` executable used when auto-spawning. |
| `-h`, `--help` | | Print help documentation. |
| `-V`, `--version` | | Print version information. |

## Subcommands

### `daemon`
Manage the background `neutrinod` supervisor daemon.

```bash
neutrino daemon start [--foreground]
neutrino daemon status
neutrino daemon stop
```

---

### `send`
Transmit a file or directory archive over an Ephemeral File Beam transfer.

```bash
neutrino send <PATH> [OPTIONS]
```

| Option | Argument | Description |
| :--- | :--- | :--- |
| `<PATH>` | Required | Local path to the file to beam. |
| `--chunk-size` | `<MB>` | Chunk boundary size in Megabytes (default: `1`). |
| `--max-speed`, `--max-mbps` | `<MBPS>` | Rate-limit outbound bandwidth in Megabits per second. |
| `--json` | | Output a machine-readable JSON transfer completion receipt. |

---

### `receive`
Receive an Ephemeral File Beam transfer using a session code.

```bash
neutrino receive <CODE> [DESTINATION] [OPTIONS]
```

| Option | Argument | Description |
| :--- | :--- | :--- |
| `<CODE>` | Required | Ephemeral transfer session token. |
| `[DESTINATION]` | Optional | Destination directory (default: current working directory). |
| `--out` | `<DIR>` | Output directory override. |
| `-y`, `--yes` | | Automatically accept transfer prompt without interactive confirmation. |
| `--json` | | Emit machine-readable completion receipt on stdout. |

---

### `sync`
Multi-host folder synchronization commands.

```bash
neutrino sync share <PATH> <NAME>
neutrino sync join <CODE> <DESTINATION>
neutrino sync status
neutrino sync list
neutrino sync scan [SHARE_ID]
```

---

### `git`
Serverless Singularity Git operations.

```bash
# Host a repository
neutrino git host <PATH> [--allow <PUBKEY>...]

# Clone a remote repository
neutrino git clone <CODE> [DESTINATION]
```

---

### `tunnel`
Encrypted virtual mesh VPN tunnel operations.

```bash
# Bring up a point-to-point tunnel interface
neutrino tunnel up <TARGET_PEER> [--virtual-ip <IP>]

# Teardown an active tunnel
neutrino tunnel down <INTERFACE>

# View active tunnels and real-time bandwidth metrics
neutrino tunnel status
```
