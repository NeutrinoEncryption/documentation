## Architectural boundaries

Network sockets, cryptography, staging I/O, and supervision belong to the daemon and core crates. The CLI sends authenticated local RPC and renders events. Preserve the 16 MiB transfer window, 32 MiB requested socket buffers, chunk and root verification, atomic staging, and receiver commit acknowledgement when changing transfer behavior.

Core sync engines, Git packfile plumbing, TUN/Wintun adapters, and their CLI/RPC entries are development interfaces. Component tests and registered types do not establish release readiness. Require end-to-end evidence at the scope claimed.

See [IPC](/api-reference/json-rpc), [wire framing](/protocol/nwp-v2-wire), and [flow control](/protocol/flow-control).
