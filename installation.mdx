## Install

<Tabs>
<Tab title="Linux / macOS">
```bash
curl -fsSL https://neutrinoapi.peretas.live/install.sh | sh
```
Pin v0.3.1 by passing the variable to the shell executing the installer:
```bash
curl -fsSL https://neutrinoapi.peretas.live/install.sh | NEUTRINO_VERSION=v0.3.1 sh
```
</Tab>
<Tab title="Windows">
```powershell
irm https://neutrinoapi.peretas.live/install.ps1 | iex
```
Pin a version in the current PowerShell session:
```powershell
$env:NEUTRINO_VERSION = 'v0.3.1'
irm https://neutrinoapi.peretas.live/install.ps1 | iex
```
</Tab>
</Tabs>

Run `neutrino --version`. The installer installs both `neutrino` and `neutrinod`. Keep them together so automatic daemon startup finds the sibling binary. Open a new terminal if needed for `PATH` changes.

## Update

Finish active transfers and rerun the installer. It stops the daemon, replaces both binaries, and preserves the data directory. Remove `NEUTRINO_VERSION` from your environment to follow latest again.

## Manual downloads

Use the [latest download directory](https://neutrinoapi.peretas.live/dl/latest/) or [v0.3.1](https://neutrinoapi.peretas.live/dl/v0.3.1/). Downloads come from the Neutrino server rather than GitHub Releases.

| Platform | Target |
| --- | --- |
| Linux x86_64 | `x86_64-unknown-linux-musl` |
| Linux ARM64 | `aarch64-unknown-linux-musl` |
| macOS Apple silicon | `aarch64-apple-darwin` |
| macOS Intel | `x86_64-apple-darwin` |
| Windows x86_64 | `x86_64-pc-windows-msvc` |

Download `SHA256SUMS` from the same release directory and compare your archive's SHA-256 before extracting both executables onto your `PATH`.

<CodeGroup>
```bash Linux
sha256sum YOUR_DOWNLOADED_ARCHIVE
```
```bash macOS
shasum -a 256 YOUR_DOWNLOADED_ARCHIVE
```
```powershell Windows
Get-FileHash .\YOUR_DOWNLOADED_ARCHIVE -Algorithm SHA256
```
</CodeGroup>

Checksums detect corrupted downloads; they are not independent release signatures.

## Uninstall

The installers can stop the daemon and remove their managed PATH entries. On Unix, run the downloaded script with `--uninstall`. On Windows, set `$env:NEUTRINO_UNINSTALL = '1'`, rerun the web installer, then clear that variable. Data remains unless you explicitly select purge. See [Installers](/api-reference/installers) for all flags, variables, exact purge directories, output, and rollback behavior. Manual removal is also possible as described below.

Finish active transfers, then stop the daemon:

```bash
neutrino daemon stop
```

Remove both installed executables on Linux or macOS:

```bash
rm -f ~/.local/bin/neutrino ~/.local/bin/neutrinod
```

On Windows, remove the installer directory in PowerShell:

```powershell
Remove-Item -LiteralPath "$env:LOCALAPPDATA\Programs\Neutrino" -Recurse -Force
```

If you installed manually somewhere else, remove the two executables from that location. Remove the installation directory from your user `PATH` if you added it manually.

Uninstalling binaries leaves your configuration and transfer state intact. Data normally lives at `~/.local/share/neutrino` (or `$XDG_DATA_HOME/neutrino`) on Unix and `%LOCALAPPDATA%\neutrino` on Windows. A custom `NEUTRINO_DATA_DIR` or `--data-dir` changes this. Inspect that directory before deleting it; deleting state can prevent resume. Your sent and received files remain wherever you chose to store them.
