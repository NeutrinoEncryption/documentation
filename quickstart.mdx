## Current limitation

Transfers currently connect directly to the sender's locally selected address. Use loopback or a reachable LAN. Automatic internet discovery, NAT traversal and relay fallback are not integrated; peers on separate home networks will typically be unable to connect.

## Build

Build the workspace with a supported Rust toolchain:

```bash
cargo build --release
```

Make `neutrino` and `neutrinod` from `target/release` available on both machines. The CLI can start the local daemon automatically.

## Send and receive

On the sender:

```bash
neutrino send ./file.txt
```

On the receiver, use the actual `neu1_` session code printed by the sender:

```bash
neutrino receive <SESSION_CODE> ./downloads/
```

The code includes an authentication secret and an address. Share it only with the intended recipient and do not post it or include it in logs. The sender must stay running and its advertised UDP address must be reachable. Use `neutrino --help` for current options.
