---
title: "Quickstart"
description: "Install v0.3.1 and transfer a file or folder between two machines."
---

<Steps>
<Step title="Install on both machines">
<CodeGroup>
```bash Linux / macOS
curl -fsSL https://neutrinoapi.peretas.live/install.sh | sh
```
```powershell Windows
irm https://neutrinoapi.peretas.live/install.ps1 | iex
```
</CodeGroup>
Run `neutrino --version`. See [installation](/installation) for downloads and version pinning.
</Step>
<Step title="Send a file or folder">
On the sender:
```bash
neutrino send ./my-folder
```
Keep it running. Share the complete `neu1_...` code privately with the recipient.
</Step>
<Step title="Receive and wait for verification">
On the recipient, replace the example code with the actual invitation:
```bash
neutrino receive neu1_REPLACE_WITH_ACTUAL_CODE ./downloads
```
Accept the prompt. The folder arrives as `./downloads/my-folder`. Both CLIs auto-start their local daemon. The sender reports success only after the receiver confirms a verified commit.
</Step>
</Steps>

<Note>Neutrino tries a direct connection first, then coordinated NAT hole punching, and only then the encrypted relay. The CLI prints `Path: direct`, `Path: direct (hole-punched)`, or `Path: relay`. Both peers need v0.3.0 or newer for relay rendezvous; install v0.3.1 for the latest connection improvements.</Note>

Use `-y` to accept automatically and `--json` for a completion receipt. Receipts include the invitation; protect them as secrets. See the [CLI reference](/api-reference/cli) and [troubleshooting](/guide/troubleshooting).
